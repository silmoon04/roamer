# Roamer demo video

[Watch or download the 61-second demo](https://raw.githubusercontent.com/silmoon04/roamer/main/docs/video/roamer-demo.mp4).

[![Roamer live scenario video](video/roamer-demo-poster.png)](https://raw.githubusercontent.com/silmoon04/roamer/main/docs/video/roamer-demo.mp4)

The video uses actual footage from a dedicated tester's live service run. Waiting is shortened and explicitly labelled. The final desktop and mobile views show the saved results from that same run. The footage does not use the synthetic fixtures shown separately in the README screenshots.

The recording shows the initial website interaction and research progress, followed by saved conversation and result views. Those later views include the no-driving requirement, stay replacement and departure-date change; the edit does not show every request being typed or every click. The final comparison uses 13–18 October 2026 and shows £113 for return flights plus £258.62 for the whole stay. The interface rounds the combined £371.62 to £372.

Transport and other suitability checks remained incomplete. The video is not evidence of a fully checked trip. The unedited timings and browser deadlines are documented in the [live-run report](LIVE-RUN.md), including the difference between provider check timestamps, database commits and visible updates.

Editing waiting time does not establish real-time response speed. This is a silent, captioned recording of website text interaction. Native Grok voice remains unverified.

The MP4 is H.264, 1440 × 1120 pixels, 61 seconds and approximately 1.46 MB. It contains no sign-in screens or raw debug exports.
