# Design skill candidate research

Checked 26 September 2026. Primary-source review only; no skills installed or quality benchmark run. Repository popularity indicates adoption, not reconstruction accuracy.

## Impeccable — recommended for design direction and refinement

The current Codex skill is named `impeccable`, so it does not collide with Anthropic's `frontend-design`. It provides focused typography, layout, critique, accessibility, responsive and polish workflows. Its actual skill explicitly gives the user's pinned aesthetics priority and distinguishes preserving an existing design from redesigning it. This makes it a strong companion to browser reference capture. It is not itself a website cloning engine. [Codex skill](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/SKILL.md)

Official installation: run `npx impeccable install` in the project root, select Codex and the desired scope, then invoke `$impeccable init`. Useful later requests include `$impeccable critique`, `$impeccable typeset`, `$impeccable layout`, and `$impeccable polish`. Codex uses `$impeccable` or `/skills`, despite generic slash syntax in some examples. The installer also adds a design-detector hook; the README says Codex's `/hooks` trust step is required. Project files live in `.agents/skills/`; user scope lives in `~/.agents/skills/`. [README and installation](https://github.com/pbakaus/impeccable)

This is now a substantial workflow, not just a small prompt: its launcher runs a bundled or downloaded version-pinned binary; Windows has a `.cmd` launcher. New visual work defaults to generated compositions when image generation is available, with visual direction choices. For faithful recreation, explicitly pin the supplied reference and disallow creative rearrangement. For inspiration, explain which qualities should transfer and which content/structure should be original. Its bounded screenshot review stops after an initial review and one confirmation round; pixel-level reproduction may need a separately scoped parity pass. [Skill](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/SKILL.md), [new-work workflow](https://github.com/pbakaus/impeccable/blob/main/skill/reference/new-work.md)

Live mode edits local projects, not deployed production websites. Production inspection uses the detector or browser extension. Current README includes Windows hook support; the older Windows POSIX-guard issue is closed. [Live-mode boundary](https://github.com/pbakaus/impeccable#live-mode-and-production-sites), [Windows issue](https://github.com/pbakaus/impeccable/issues/452)

Adoption snapshot: GitHub API reported 71,399 stars and a push on 26 September; latest main commit was 25 September. Skills.sh displayed 294.3K installs. Skill metadata reads 4.4.0; latest GitHub release is a separately versioned engine-v0.1.6, not necessarily the npm/skill version. [GitHub metadata](https://api.github.com/repos/pbakaus/impeccable), [skills.sh](https://skills.sh/pbakaus/impeccable/impeccable), [engine release](https://github.com/pbakaus/impeccable/releases/tag/engine-v0.1.6)

## img-to-frontend — optional for generating visual concepts

The `am-will/codex-skills` implementation generates four image concepts, waits for the user to choose, translates the selected image into an implementation brief, then compares real browser screenshots at several viewport sizes. The responsive/fidelity checklist is useful. However, its mandatory first deliverable is four generated images even when a screenshot is supplied. That makes it a poor default for directly recreating an existing website; it is better for exploring new art directions before coding. [Actual skill](https://github.com/am-will/codex-skills/blob/main/skills/img-to-frontend/SKILL.md)

The repository documents installation through skills.sh with a named skill and Codex agent target; the corresponding command is `npx skills add am-will/codex-skills --skill img-to-frontend -a codex -g`. The repository README's inventory does not currently list this skill, although its file exists. API snapshot: 1,033 stars, last push 14 July 2026, no GitHub release and no license identified by the repository API. [README](https://github.com/am-will/codex-skills), [metadata](https://api.github.com/repos/am-will/codex-skills)

## UI Image to Code Studio — experimental, not the default recommendation

Explicitly targets Codex screenshot/URL recreation into React, Vue or HTML, with evidence maps, interaction capture, browser parity and editable Studio layers. Its README and install guide support Windows PowerShell, Python 3.10+, Node 18+, and installation of `skill/` into the Codex skills directory. [Repository](https://github.com/zwq-top/ui-image-to-code-studio), [installation](https://github.com/zwq-top/ui-image-to-code-studio/blob/main/docs/INSTALL_AND_RUN.md)

The actual skill imposes a large mandatory contract: source provenance, icon audits, browser replay, Studio import, source roundtrip and rollback, plus sign-offs from three named companion skills. Its companion reference says missing companions are optional, but the main skill explicitly makes the stricter gates authoritative. This tension and extensive workflow overhead make it hard to recommend for casual website inspiration or one-page reproduction. Its default source-blind capture also excludes DOM/CSS inspection, which may be unnecessary for the user's own site. [Actual skill](https://github.com/zwq-top/ui-image-to-code-studio/blob/main/skill/SKILL.md), [companion workflow](https://github.com/zwq-top/ui-image-to-code-studio/blob/main/skill/references/orchestration-workflow.md)

The public project was created 15 August 2026, has 2 stars and no forks, last push 26 August, MIT license, and release v0.1.2. Its maintenance document promises active support for 0.1.x, but this is early evidence of adoption rather than proof of broad reliability. Keep it on a watchlist or test in a throwaway project if editable visual layers are specifically wanted. [Metadata](https://api.github.com/repos/zwq-top/ui-image-to-code-studio), [maintenance](https://github.com/zwq-top/ui-image-to-code-studio/blob/main/MAINTENANCE.md), [release](https://github.com/zwq-top/ui-image-to-code-studio/releases/tag/v0.1.2)

## Practical recommendation

Start with Impeccable plus the browser capabilities already available. Inspect the reference at desktop and mobile sizes, record layout/type/color/spacing and interaction states, then choose explicitly between faithful reproduction and an original design inspired by those qualities. Match screenshots at equal viewports and fix the largest geometric differences first. Use a separate accessibility/responsive audit after the visual implementation. A highly specific reference and measured comparison are more valuable to reproduction than installing several competing aesthetic skills.
